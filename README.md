# Рекламации — сайт озвучивания

Веб-приложение для озвучивания текстов рекламаций голосом. Пользователь добавляет текст рекламации, нажимает «Озвучить» — текст произносится естественным нейросетевым голосом (Silero TTS, синтез на сервере) с пословной подсветкой на экране в стиле «экран зала». Рекламации хранятся в PostgreSQL: их можно добавлять, редактировать и удалять.

## Запуск в Docker (рекомендуемый способ)

Нужны только Docker и Docker Compose — Node и PostgreSQL ставить не надо, база поднимается в соседнем контейнере автоматически:

```bash
docker compose up -d --build
```

Сайт откроется на http://localhost:3012. Данные PostgreSQL хранятся в докер-томе `pgdata` и переживают перезапуски и пересборки.

Настройки (опционально, через переменные окружения или файл `.env` рядом с `docker-compose.yml`):

- `PORT` — внешний порт сайта (по умолчанию 3012);
- `POSTGRES_PASSWORD` — пароль базы (по умолчанию `reklam`; для сервера, доступного извне, задайте свой);
- `TTS_VOICE` — голос озвучки: `baya` (по умолчанию) или `kseniya` — женские, `aidar`, `eugene` — мужские, `xenia`;
- `TTS_THREADS` — число CPU-потоков синтеза (по умолчанию 4).

Полезные команды: `docker compose logs -f app` — логи, `docker compose down` — остановить (данные останутся), `docker compose down -v` — остановить и стереть базу.

## Запуск без Docker

Требуются Node.js ≥ 18 и PostgreSQL (проверено на 16).

1. Создайте базу и пользователя (один раз):

```sql
CREATE ROLE reklam LOGIN PASSWORD 'reklam';
CREATE DATABASE reklam OWNER reklam;
```

2. Установите зависимости и запустите:

```bash
npm install
DATABASE_URL=postgres://reklam:reklam@localhost:5432/reklam npm start
```

Сайт откроется на http://localhost:3012 (порт меняется переменной `PORT`).

Таблица создаётся автоматически при первом запуске и заполняется тремя примерами рекламаций.

### Настройка подключения

Либо одной строкой `DATABASE_URL=postgres://user:pass@host:5432/dbname`, либо стандартными переменными окружения pg: `PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` (по умолчанию база `reklam`). Если PostgreSQL недоступен при старте, сервер повторяет попытки подключения ~30 секунд, затем завершается с ошибкой.

## Возможности

- **Озвучка** — кнопка «Озвучить» читает текущую рекламацию естественным русским голосом. Синтез идёт на сервере нейросетевой моделью Silero TTS v4 (бесплатно, локально, без внешних API), браузер получает готовый WAV. Слова подсвечиваются по ходу речи, круг на экране «дышит» от реальной амплитуды звука. Пауза, продолжение, стоп. Готовое аудио кэшируется — повторная озвучка мгновенная. Автопроигрывания нет — только по нажатию. Если сервис озвучки недоступен, страница автоматически откатывается на голос браузера (Web Speech API).
- **Управление рекламациями** — кнопка «Рекламации» открывает панель: добавление нового текста через поле ввода, редактирование и удаление существующих. Дополнительно к тексту можно указать краткую проблему, уровень (федеральный/региональный/муниципальный) и статус.
- **Навигация** — стрелки ← → на панели или клавиатуре, пробел — озвучить/пауза.

## Архитектура

```
server.js            — HTTP-сервер (node:http): статика + REST API + прокси /api/tts с кэшем
db.js                — слой PostgreSQL (пул pg), схема и CRUD
public/              — фронтенд: index.html, styles.css, app.js
tts/                 — сервис озвучки: Silero TTS v4 (Python + PyTorch CPU)
Dockerfile           — образ приложения (node:22-alpine)
docker-compose.yml   — приложение + PostgreSQL 16 + сервис озвучки
```

### REST API

| Метод  | Путь                    | Описание                     |
|--------|-------------------------|------------------------------|
| GET    | `/api/reklamations`     | список рекламаций            |
| POST   | `/api/reklamations`     | создать (`{text, problem?, level?, status?}`) |
| PUT    | `/api/reklamations/:id` | обновить                     |
| DELETE | `/api/reklamations/:id` | удалить                      |
| POST   | `/api/tts`              | озвучить текст (`{text}` → audio/wav) |

## Примечания

- Сервис озвучки — контейнер `tts` (~1,5 ГБ из-за PyTorch, модель всего 40 МБ). Синтез на CPU в 3–4 раза быстрее реального времени; рекомендуется сервер минимум с 2 ГБ ОЗУ. Первый запрос на пункт занимает несколько секунд, дальше отдаётся из кэша.
- Запуск без Docker и без сервиса озвучки тоже работает: не задавайте `TTS_URL`, и страница будет использовать голос браузера (Web Speech API).
- Для хостинга: приложению нужен VPS или облачный сервер (Node-процессы и Docker), на обычном виртуальном хостинге стек не запустится.
- Дизайн — режим «экран зала»: крупный анимированный круг и крупный текст, рассчитан на показ на большом экране.
