# Рекламации — сайт озвучивания

Веб-приложение для озвучивания текстов рекламаций голосом. Пользователь добавляет текст рекламации, нажимает «Озвучить» — текст произносится синтезатором речи (Web Speech API) с пословной подсветкой на экране в стиле «экран зала». Рекламации хранятся в базе данных: их можно добавлять, редактировать и удалять.

## Запуск

Требуется Node.js ≥ 22.5 (используется встроенный модуль `node:sqlite`). Внешних зависимостей нет — `npm install` не нужен.

```bash
npm start
# или: node --no-warnings server.js
```

Сайт откроется на http://localhost:3000 (порт меняется переменной окружения `PORT`).

## Возможности

- **Озвучка** — кнопка «Озвучить» читает текущую рекламацию русским голосом (Web Speech API), слова подсвечиваются по мере произношения, круг на экране «дышит» в такт речи. Пауза, продолжение, стоп. Автопроигрывания нет — каждая рекламация озвучивается только по нажатию.
- **Управление рекламациями** — кнопка «Рекламации» открывает панель: добавление нового текста через поле ввода, редактирование и удаление существующих. Дополнительно к тексту можно указать краткую проблему, уровень (федеральный/региональный/муниципальный) и статус.
- **Навигация** — стрелки ← → на панели или клавиатуре, пробел — озвучить/пауза.

## Архитектура

```
server.js   — HTTP-сервер без зависимостей: статика + REST API
db.js       — слой SQLite (node:sqlite), схема и CRUD
public/     — фронтенд: index.html, styles.css, app.js
data/       — reklam.db (создаётся автоматически, в git не попадает)
```

### REST API

| Метод  | Путь                    | Описание                     |
|--------|-------------------------|------------------------------|
| GET    | `/api/reklamations`     | список рекламаций            |
| POST   | `/api/reklamations`     | создать (`{text, problem?, level?, status?}`) |
| PUT    | `/api/reklamations/:id` | обновить                     |
| DELETE | `/api/reklamations/:id` | удалить                      |

При первом запуске база заполняется тремя примерами рекламаций.

## Примечания

- Голос берётся из установленных в системе/браузере голосов: предпочитается локальный русский (`ru-*`). Если синтезатор не сообщает границы слов (Chrome с удалёнными голосами), подсветка идёт по оценке темпа речи.
- Дизайн — режим «экран зала»: крупный анимированный круг и крупный текст, рассчитан на показ на большом экране.
